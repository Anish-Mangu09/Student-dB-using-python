# Student Database System

A Python-based Student Database Management System that demonstrates Object-Oriented Programming (OOP) concepts and CRUD operations through a menu-driven interface.

## Features

* Add Student Records
* Display All Students
* Search Student by ID
* Update Student Marks
* Delete Student Records
* Encapsulation using Private Attributes
* Simple Command-Line Interface (CLI)

## Technologies Used

* Python 3
* Object-Oriented Programming (OOP)

## Concepts Implemented

* Classes and Objects
* Constructors (`__init__`)
* Encapsulation
* Methods
* Lists
* CRUD Operations
* Menu-Driven Programming

## How to Run

1. Clone the repository:

   git clone https://github.com/Anish-Mangu09/Student_Database_Management_System.git

2. Navigate to the project folder:

   cd Student_Database_Management_System

3. Run the program:

   python StudentDatabase.py
